# Киберспорт Телеком

Адаптивный демо-сайт о киберспорте: матчи, команды, игроки, турниры и призовые фонды.

## Запуск

Откройте `outputs/index.html` в браузере. Сборка и установка зависимостей не требуются.

## Возможности

- Отдельные разделы матчей, команд, игроков и турниров.
- Карточки со статистикой и результатами.
- Фильтры по играм и сортировка рейтинга команд.
- Поиск по игрокам, командам и матчам.
- Адаптивная вёрстка и казахский орнамент в оформлении.

Все данные на сайте демонстрационные и могут не совпадать с официальной статистикой.
